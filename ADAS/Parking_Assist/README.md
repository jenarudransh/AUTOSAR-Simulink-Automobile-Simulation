# Parking Assist System

This directory contains a Simulink model that simulates an automatic Parking Assist system. The controller is designed to follow a predefined path to steer a vehicle into a parking spot.

## Overview

This project uses a **Stanley Controller** as the path-following algorithm. The controller's job is to calculate the necessary steering angle to keep the vehicle on a pre-calculated path. The vehicle itself is modeled using a **Kinematic Bicycle Model**, which is well-suited for low-speed steering maneuvers like parking.

## Files in This Directory

* **`Parking_Assist.slx`**: The main Simulink model. This file contains the complete feedback loop, including the Stanley Controller, the vehicle model, and the path data.
* **`createParkingPath.m`**: A MATLAB script used to define and save the parking trajectory. It creates a set of `[x, y, heading]` waypoints and saves them to a `.mat` file.
* **`ParkingPath.mat`**: The MATLAB data file generated by the script. It contains the `path_waypoints` variable that is loaded by the controller.
* **`pose.slx`**: (This file might be an auxiliary model or subsystem, possibly containing the vehicle dynamics logic).

## System Logic

1.  **Path Generation**: The `createParkingPath.m` script is run once to generate the reference path and save it as `ParkingPath.mat`.
2.  **Controller (Stanley Controller)**: The `StanleyController` block (a MATLAB Function block) is the "brain." It loads the path from `ParkingPath.mat` and continuously:
    * Calculates the vehicle's **Heading Error** (angle difference) and **Cross-Track Error** (distance) from the path.
    * Uses the Stanley control law to output the precise `SteeringCommand` needed to minimize both errors.
3.  **Vehicle Model**: A subsystem models the vehicle's kinematics. It takes the `SteeringCommand` and a constant speed, then integrates them over time to output the vehicle's new position and heading (`pose`).
4.  **Feedback Loop**: The vehicle's `pose` is fed back to the controller, allowing it to see the results of its commands and make continuous corrections.

## How to Use

1.  **Open MATLAB**.
2.  **Create the Path**: Run the `createParkingPath.m` script once to generate the `ParkingPath.mat` file.
3.  **Open the Model**: Open `Parking_Assist.slx` in Simulink.
4.  **Run Simulation**: Run the simulation.
5.  **View Results**: Open the **XY Graph** block to visualize the vehicle's path. You will see the vehicle's trajectory (the blue dots) follow the pre-defined path into the parking spot.
